# Mutango Boss Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## Goal

Bring the standalone Mutango Paper plugin (package `dev.linqfy.mutango`, built and playtested separately) into
BigCasares as the `mutango` module, reusing the BigCasares module lifecycle, resource-pack pipeline and BetterModel
model folder instead of the standalone plugin's own main class and two HTTP pack servers. Design:
[2026-10-16-mutango-design.md](../specs/2026-10-16-mutango-design.md).

## Tech Stack

- Paper API 26.2.build.56-alpha, Java 25, Gradle 9.2.1.
- BetterModel API 3.2.0 at compile time (server runs 3.5.0; `EntityTracker.spawnCondition` is used reflectively).
- Unit tests: JUnit 5 against `spigot-api:26.2-R0.1-SNAPSHOT`.

## File Structure

New:
- `src/main/java/dev/linqfy/bigCasares/modules/mutango/*.java`: the module (about 55 classes).
- `src/test/java/dev/linqfy/bigCasares/modules/mutango/*Test.java`: pure-rule tests plus the wiring/contract test.
- `src/main/resources/mutango.yml`: module settings (`bedrock` section).
- `src/main/resources/bettermodel/models/bigcasares_*.bbmodel`: 28 models (Mutangos, statues, Neguechen, hands, Sun, Moon,
  shrine cube, 16 armored versions).
- `src/main/resources/mutango/`: ruins structure, GeyserModelEngine inputs, Bedrock icon pack for the rewards.
- `resourcepack/java/assets/mutango/`: item definitions, item models and textures of the two rewards.
- `docs/mutango/README.md`, this plan and its spec.

Modified:
- `BigCasares.java`: construct, register and expose `MutangoModule`.
- `config.yml`: `modules.mutango.enabled: true`.
- `plugin.yml`: `/mutango` command, `bigcasares.mutango.admin` permission, `GeyserModelEngine` softdepend.

## Boundaries

- No changes to other modules or to `build.gradle`.
- No changes to the BigCasares resource-pack or Geyser module code.
- No own HTTP pack server; no `getConfig()`/`saveDefaultConfig()` of the BigCasares plugin for module settings.
